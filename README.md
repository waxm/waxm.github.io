# WAXM Playground

WAXM 的游戏统一展示站，用于集中展示并在线体验独立游戏和交互原型。

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

推送到 `main` 后，GitHub Actions 会自动构建并发布到
[`https://waxm.github.io/`](https://waxm.github.io/)。
